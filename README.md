# Introduction to GitHub

Repository thực hành GitHub Skills của `nhatpro306`, dùng để học quy trình branch → commit → pull request → merge.

## Bắt đầu bài học

Mở [issue bài tập](https://github.com/nhatpro306/skills-introduction-to-github/issues/1) để xem hướng dẫn và phản hồi của workflow. Đây là repo bài học; không cần cài dependency hay chạy ứng dụng.

| Bước | Hướng dẫn trong repo |
| --- | --- |
| 1. Tạo branch | [Create a branch](.github/steps/1-create-a-branch.md) |
| 2. Commit file | [Commit a file](.github/steps/2-commit-a-file.md) |
| 3. Mở pull request | [Open a pull request](.github/steps/3-open-a-pull-request.md) |
| 4. Merge pull request | [Merge your pull request](.github/steps/4-merge-your-pull-request.md) |
| Ôn tập | [Review](.github/steps/x-review.md) |

Workflow của khóa học nằm trong [`.github/workflows/`](.github/workflows/). Bước commit kiểm tra branch `my-first-branch` và file `PROFILE.md`; làm theo tên trong bài tập để workflow nhận đúng sự kiện. Trạng thái hoàn thành nằm ở issue và lịch sử Actions, không được suy ra từ nội dung README.

Không có lệnh build/lint/unit test cho repo này. Khi sửa tài liệu, kiểm tra link tương đối và giữ nguyên cấu trúc workflow của bài học.
